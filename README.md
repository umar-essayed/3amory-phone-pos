# Mobile POS Pro | نظام كاشير وإدارة محلات الموبايل المتكامل

نظام كاشير ونقاط بيع وإدارة متكامل مصمم خصيصاً لتلبية كافة احتياجات محلات الموبايل في السوق المصري والعربي.

---

## 🌟 الميزات الجوهرية للنظام

### 1. قابلية التخصيص الكاملة لأي محل (White-label 100%)
- إمكانية تغيير **اسم المحل** (بالعربية والإنجليزية).
- رفع **لوجو وشعار المحل** الخاص وتطبيقه على كافة الشاشات والفواتير الحرارية.
- تخصيص أرقام الهاتف، رقم الواتساب لخدمة العملاء، والعنوان بالتفصيل.
- السجل التجاري والبطاقة الضريبية.
- تخصيص ترويسة وتذييل الفاتورة الحرارية وسياسة الاستبدال والضمان.
- اختيار مقاس ورق الطباعة (80mm أو 58mm) والعملة (ج.م أو غيرها).

### 2. وحدة فودافون كاش وإنستاباي الحساسة (⚡ سرعة فائقة)
- تتبع أرصدة خطوط ومحافظ المحل (فودافون كاش 1، فودافون كاش 2، إنستاباي بنك مصر، أورنج، اتصالات، وي).
- **إيداع للعميل (تحويل من محفظة المحل):** حساب العمولة تلقائياً بنظام الشرائح الذكي، زيادة كاش الدرج، وخصم رصيد المحفظة.
- **سحب من العميل:** العميل يحول لمحفظة المحل والمحل يسلمه كاش من الدرج مخصوماً منه العمولة.
- **تحويلات إنستاباي البنكية المباشرة.**
- **التحويل الداخلي بين خطوط ومحافظ المحل.**
- طباعة إيصالات فورية لعمليات التحويل والسحب.

### 3. إدارة الهواتف (الجديدة والمستعملة) وتتبع الـ IMEI
- تسجيل الجهاز بالماركة، الموديل، اللون، السعة، ورقم الـ IMEI 1 و IMEI 2.
- فحص نسبة البطارية (Battery Health %) والحالة الظاهرية للأجهزة المستعملة.
- **الحماية القانونية الحازمة:** تسجيل بيانات البائع (الاسم، الرقم القومي، الهاتف) وطباعة **"عقد وإقرار بيع وتنازل هاتف مستعمل"** رسمي وموقع لحماية المحل من أي شبهات أجهزة مسروقة.
- منع تكرار أو إعادة تسجيل أي جهاز برقم IMEI مسجل مسبقاً.

### 4. إدارة الإكسسوارات ومولد الباركود
- تصنيفات مرنة (جرابات، سكرينات، شواحن، كابلات، سماعات، ساعات، باور بنك، قطع غيار).
- **مولد باركود تفاعلي:** توليد باركود تلقائي أو مخصص لأي صنف وطباعة ملصقات الباركود والأسعار.
- تسعير قطاعي وجملة.
- تنبيهات فورية للنواقص عند وصول الصنف لحد الطلب.

### 5. ورشة وقسم الصيانة المتكامل
- كارت استلام جهاز للصيانة (بيانات العميل، الموديل، IMEI، العطل، رمز القفل Pattern/PIN، المتعلقات).
- طباعة **إيصال استلام صيانة** فوري للعميل مع QR كود لمتابعة الحالة وشروط الضمان وإخلاء المسؤولية.
- دورة حياة حالة الصيانة: (تم الاستلام ➔ قيد الفحص ➔ انتظار الموافقة ➔ جاري الإصلاح ➔ تم الإصلاح وجاهز للتسليم ➔ تم التسليم والتحصيل).
- خصم قطع الغيار المستهلكة من المخزن وحساب عمولة الفني وصافي ربح المحل.

### 6. شاشة البيع السريع (POS Terminal)
- واجهة سريعة تدعم قارئ الباركود واختصارات الكيبورد.
- إضافة هواتف جديدة، مستعملة، إكسسوارات، أو خدمات للسلة.
- دعم تعليق الفواتير (Hold / Resume) واستئناف البيع لزبون آخر.
- طرق دفع متعددة: كاش، محفظة إلكترونية، إنستاباي، أو آجل لعميل مسجل.
- طباعة حرارية فورية متطابقة مع طابعات 80mm و 58mm.

### 7. الورديات والخزينة (Shifts & Cash Management)
- فتح وردية برصيد كاش افتتاحي بالدرج.
- تسجيل المصروفات النثرية اليومية (بوفيه، إيجار، نثريات).
- إغلاق الوردية وجرد النقدية بالدرج، وحساب العجز والزيادة تلقائياً.
- طباعة تقرير تقفيل الوردية المالي (Z-Report).

### 8. التحليلات والتقارير المالية المتقدمة
- تقارير الأرباح الصافية (Net Profit) لكل قطاع: (مبيعات الأجهزة، الإكسسوارات، عمولات فودافون كاش، وورشة الصيانة).
- فلترة الفترات (اليوم، آخر 7 أيام، هذا الشهر، كل الفترات).
- سجل الفواتير والمبيعات الكامل وإعادة طباعة أي فاتورة سابقة.

### 9. الحسابات والديون (العملاء والموردين)
- سجل ديون العملاء ومدفوعات الآجل (شكك).
- مستحقات الموردين وفواتير شراء البضاعة.

### 10. الأوفلاين والسحابة (Offline-First + Firebase Cloud)
- **أوفلاين 100%:** يعمل النظام محلياً عبر قاعدة بيانات IndexedDB (Dexie) بسرعة فائقة حتى لو انقطع الإنترنت تماماً عن المحل.
- **Firebase Sync:** إمكانية ربط مشروع Firebase الخاص بصاحب المحل للمزامنة السحابية ومتابعة المحل عن بعد.
- **النسخ الاحتياطي الكامل:** تصدير نسخة احتياطية من كافة بيانات المحل بملف JSON بنقرة واحدة، واستعادتها في أي وقت.

## 🚀 تشغيل النظام

```bash
# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build
```

- رابط التطبيق المحلي: `http://localhost:5173/`
- يمكنك الدخول من أي جهاز متصل على نفس شبكة الواي فاي أو الراوتر في المحل عبر IP الجهاز.
